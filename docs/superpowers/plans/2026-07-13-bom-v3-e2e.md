## Phase 5 — full corpus export and browser load

For each source model:

1. Open directly through SketchUp UI.
2. Zoom extents.
3. Recapture inventory and six matched cameras.
4. Export canonical JSON v3, canonical gzip, BOME2, BOME2 gzip, and optional GLB benchmark.
5. Validate schema/container.
6. Load BOME2 in browser model-eval.
7. Inspect hierarchy, materials, transforms, instances, normals, winding, scale, origin, and axes.
8. Save browser console/network errors and matched screenshots.
9. Continue after individual failure; record explicit verdict.
