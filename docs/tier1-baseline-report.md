# Tier-1 baseline report

Baseline evaluation aggregates the existing classifier only for measurement.
It is area-weighted at classification-unit level in a later evaluation pass;
this iteration does not tune rules, thresholds, or weights.

There are currently zero verified annotations. Therefore no precision, recall,
F1, macro F1, balanced accuracy, or class score is reported. Existing
source-label and classifier metrics remain silver metadata and are not
authoritative ground truth.
