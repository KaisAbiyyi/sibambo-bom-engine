# Sibambo BOM Engine React UI Draft 02

This draft is isolated in `react-2`.

It does not modify `react-1`.

It does not modify `bom_engine_plugin`.

It does not modify the Ruby exporter.

It does not change JSON schema.

## Run Locally

```bash
cd react-2
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally:

```text
http://localhost:5173
```

The app opens a dark professional architectural showcase with scroll-driven 3D chapters.
